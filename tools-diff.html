这一页在哪一档上打了折

  1. 行对齐用的是本站自实现的 Myers 最短编辑脚本，代价上限 2000：越线那一段按「整块删 + 整块增」给出，行数一行不会少，只是不再替你把最相似的行两两配起来。
  2. 行内逐字高亮另有一道预算（单对 4000 个 token、整篇三百万格）：越线的那些行只按整行着色，读数里写「未行内 N」告诉你少了多少。
  3. 折叠只是阅读形状：只看差异 / 上下文 3 行 / 5 行 / 全部展开四档改变"看到多少行"，不改变差异本身；复制与下载走的是你当前这一档。
  4. 勾了「忽略空白」或「忽略大小写」之后，"相同"是一个被归一化过的结论：那些行的原文仍有差别，只是没有计入差异统计，被抹平的行数单列在读数里。
  5. 「复制差异」与「下载 .diff」得到的是一份按阅读习惯排的 unified 形状文本，不承诺能被 git apply 接住——本站不校验上下文行，也不生成可打的补丁。
  6. 两份内容都只在这一台机器上读：粘贴、拖放、选本地文件三条路都不发请求、不上传；这一页也不读写 localStorage，关掉标签什么都不留下。
