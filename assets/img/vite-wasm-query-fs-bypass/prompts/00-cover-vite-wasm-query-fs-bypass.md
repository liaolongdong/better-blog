## Prompt

Wide 16:9 flat vector illustration, cool muted palette (deep slate blue, desaturated teal, pale
gray stone, one soft amber accent), generous negative space with 45–60% breathing room, no text,
no letters, no numbers, no logos, no watermark, no signature, simplified geometric shapes only,

Scene: a high masonry wall runs vertically just left of center, dividing the frame into a private

holding an elongated unlabeled tag with a wavy zigzag scribble on it (representing a query string

crate and a stack of documents remain untouched and intact — the escape is only those four tiles, not
the contents.

Mood: quiet, procedural, slightly absurd. The composition should read as a bypassed checkpoint rather
than a break-in: no forced doors, no damage, no alarm, nothing dramatic. Soft top-left light, flat
