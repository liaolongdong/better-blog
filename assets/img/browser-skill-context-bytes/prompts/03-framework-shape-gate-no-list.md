# 这道门只拿形状比对，手里没有名单

16:9 手绘笔记风示意图。主题：一道关卡只检查"来客的门牌是不是那个形状"，
**并没有一份可以对照的名单**，于是形状一样的东西都能过。画面不出现文字、字母、数字、字符。

构图：画面正中一道单扇门，门半开，门框厚、抖线描边（#2E3A47 填充 + #1F2429 描边）。

门上：钉着一块形状模板（一块中间挖空的薄板，挖空处是一排连续的小方块孔，
孔的排列只有"形状"没有内容），模板 #9AA5B1 描边。
门右侧墙上一个空相框，框里**完全空白**（代表那张本该存在却没有的名单），
相框下沿垂着两颗没钉上去的图钉（#FF6B6B）。

门左侧：三个来客排成一小队，全部画成没有脸的简化剪影，身上各挂一块长方形门牌，
三块门牌**形状完全相同**（只画形状，牌面一律空白）。
第一个已经站在门内，第二个正跨过门槛，第三个还排在队尾。

门右侧地面：一条短虚线从门内通到画面最右端（表示"还能一直往里走"）。

小意外：在第二和第三个来客之间，画一块**掉在地上**的门牌，形状与手上那三块一模一样，
牌面朝上、依然空白（表示形状可仿造，门不区分）。

配色：底 #FDF6E3 细纸纹；门与门框 #2E3A47 + #1F2429；模板与虚线 #9AA5B1；
图钉与地上的门牌描边 #FF6B6B；三个来客近黑 #1F2429 剪影。

风格：sketch-notes，平涂无渐变，轻微抖动线条，留白 ≥30%，三个来客大小略微不齐（不复制粘贴感）。
