# 厚的那一份留在桌子下面，没有进脑子

16:9 手绘笔记风示意图。主题：一个工具的几十个方法、一张很厚的参数表，
都待在一个**进程/桌子**这一侧，靠一次一次往返去查；另一侧那颗"常驻上下文"的脑袋里
只放了一张薄纸。画面不出现文字、字母、数字。

构图分上下两层，用一条横贯画面的抖动粗线当作桌面。

桌面上方（少而薄）：左侧画一颗简化的人头侧面轮廓（只有外圈一条线，无五官、无头发细节），
头颅里只放一张竖着的薄纸（#FFD93D 描边、纸面完全空白）。
人头与桌面之间留白。桌面右上方画一个很小的、只勾两条弧的空心圆窗（代表浏览器窗口），窗内全空。

桌面下方（多而厚）：一口大方箱，箱盖半开，箱里塞满一叠叠纸，纸边画成**密但不数得清**的短横纹
（避免画出可数的具体层数）；箱子右下角露出一把小尺子（#9AA5B1），
箱子旁边靠着一张竖着的大纸，纸的中部画一个空心的方形缺口（代表"参数表里那份东西没被搬走"）。

往返线：从人头下方的桌面处引出一条向下的短箭头，箭头尖停在箱子正上方（不接触）；
再从箱子引出**一条**向上的回程线，末端画一个空心小圈（#FF6B6B）。
去和回两条线之间画一小段错开的台阶（代表多出来的一轮往返，不写数字）。

配色：底 #FDF6E3 细纸纹；桌面与箱体重色 #2E3A47 + 近黑 #1F2429 抖线描边；
薄纸 #FFD93D；尺子与回程线 #9AA5B1；空心小圈与台阶 #FF6B6B。

风格：sketch-notes，平涂无渐变，线条轻微抖动，留白 ≥30%，桌面粗线两端断开不画满。

禁止：水印、签名、边框、齿轮、电路纹、盾牌、进度条、对勾叉号、任何文字/编号/箭头上的标签、
云形图标、多个向上箭头（只允许一去一回两条线）。
