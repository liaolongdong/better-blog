# 一板旧绳结：五只结实的、两只剪断的、一只打了一半、两只还悬着

16:9 手绘笔记风示意图。主题：把过去欠下的几件事逐条对账，
每件事是一段绳子，处理结果用**绳结的不同状态**表示。画面不出现文字、字母、数字、编号。

构图：画面上方一条横向粗绳梁（手绘抖线，两端钉进左右两根短柱），
从绳梁上垂下**五组**绳子，每组之间留明显空隙；每组内部只画一根或两根绳，不画一大把。

1. 第一组（结掉）：一根绳打了一个又紧又小的死结，结画成两层交叠的环线（#FFD93D 描边），绳尾剪得很短。
2. 第二组（剪断）：两根绳的末端是**散开的毛边**，绳断口与绳梁之间留一小段空隙；
   断口下方地面躺着一把小剪刀，剪刀张开、只画轮廓（#9AA5B1）。
3. 第三组（打了一半）：一根绳只绕了一个松松的半环，环口朝上没收紧（#9AA5B1 描边），
   绳的另一头仍连着绳梁。
4. 第四组（还悬着）：一根绳垂得很长，末端什么都没有、也没断，绳尾画成一个小空心圈（#FF6B6B）。
5. 第五组（还悬着）：与第四组不同形状——绳子绕柱一圈后朝画面右侧水平拉出去，
   在画面边缘被裁断（表示"这期没量完，下期接着"）。

地面上：五组之间散落三片小纸屑（不规则小三角，#2E3A47），表示翻过账本留下的碎屑；
不要画成可读的纸页、不放任何线条充当文字。

配色：底 #FDF6E3 细纸纹；绳梁与短柱 #2E3A47 + #1F2429 抖线描边；死结 #FFD93D；
散口与剪刀、半环 #9AA5B1；空心圈 #FF6B6B。

风格：sketch-notes，平涂无渐变，线条轻微抖动，留白 ≥30%，五组绳长各不相同。

禁止：水印、签名、边框、账本上的任何文字或表格线、算盘、金币、盾牌、对勾叉号、百分比、
一根绳上打两个结（每组状态必须唯一）、可数超过五组的绳。
