# 常驻的那一格，和读到底的那一摞

16:9 手绘笔记风示意图。主题：同一个入口有两笔账——**一直挂在手边的那一张**，和
**真要读完才付的那一摞**。画面不出现文字、字母、数字、编号。

构图左右分开，中间留一条明显的竖向空白带。

左侧（常驻）：一个矮柜，只有三格，正面视角，抖线描边。
中间那格立着一张单页纸，纸占这格宽度的一半，暖黄 #FFD93D 描边、内部留白，纸面完全空白。
上格与下格空着，格板上各有一块比底色稍亮的矩形压痕（灰蓝 #2E3A47），表示"这里没放东西"。
柜顶放着一条对折的细绳（#9AA5B1），暗示"它一直在那儿"。
柜子上方悬一枚小小的方形挂钩，挂钩上什么都没有。

右侧（读到底）：一摞七张纸堆叠在一起，纸边画成七条平行抖线（不要画成十几条），
最上面一张被一只没有手指的、简化成圆弧的手形轻轻掀起一角（手形 #9AA5B1 描边，无细节）。
这摞纸旁边画一个很小的木滑轮，绳子从滑轮绕过、另一端没有系东西（按需才拉过来）。
摞底压着一张展开的大纸，纸的右下角被撕掉一小块（撕口 #FF6B6B），
表示"全读完要付的那部分里，最大的一页"。

关系线：从左侧那张单页引出一条很细的虚线到右侧那摞，虚线中段画一个空心的小圆圈（#FF6B6B），
不写任何倍数标注。

配色：底 #FDF6E3 细纸纹；柜体与纸摞侧面 #2E3A47 填充 + #1F2429 抖线描边；
单页 #FFD93D；绳与手形与虚线 #9AA5B1；撕口与小圈 #FF6B6B。

风格：sketch-notes，平涂无渐变，轻微抖动线条，留白 ≥30%，左右两块高度不齐。

禁止：水印、签名、边框、编号、任何文字或形似文字的笔画、放大镜、灯泡、书本封面文字、柱状图、坐标轴。
