# 一沓纸进了一台小机器，出来时上面少了几处标记

3:2 横构图手绘笔记风示意图。主题：同一份界面描述，进机器之前有几处小标记，
出机器之后**标记不见了，但纸的轮廓、方格的位置都还是原来的样子**。画面不出现文字、字母、数字、伪文字。

构图（从左到右一条水平流向）：
1. 画面左侧：一沓 4 层左右的奶油纸 #FDF6E3 斜靠着，最上面那张画着 4 个空心方格 + 短抖线连线，
   其中 3 处位置各有一个小小的**实心圆点标记**（#FF6B6B），另有一处是一个小方点（#FFD93D）。
   这沓纸整体比右侧那张略高一点点（表示"进去的比出来的内容多"）。
2. 画面正中：一台很小的方壳子机器（占画面高度约三分之一），机身 #2E3A47 平涂 + #1F2429 抖线描边，
   顶部一颗小圆灯亮着暖黄 #FFD93D（表示"这台机器认为一切正常"），
   左右各一个长方形口子（进纸口、出纸口），机身上**不画任何按钮排、刻度、屏幕字符**。
   左侧进纸口咬住那沓纸的最上一张，右侧出纸口吐出一张纸。
3. 画面右侧：一张出纸后的纸，方格数量、连线位置与左侧那张**完全一致**，
   但原来三处实心圆点标记**只剩很淡的虚线圆圈轮廓**，小方点完全不见。
   这张纸的右下角微微上翘。

细节：机器下方一条手绘地面横线（两端断开）。出纸口与右侧纸之间有一小段空白，
表示"纸已经离开机器"。机器正下方地面有一条短斜虚线阴影。

配色：底 #FDF6E3 细纸纹（占大面积）+ 四周留白；机器 #2E3A47 / #1F2429；
标记 #FF6B6B 与 #FFD93D；虚线轮廓 #9AA5B1。

风格：sketch-notes，平涂无渐变，线条轻微抖动，左右两张纸**画成手工感不一致**（不要镜像复制），留白 ≥30%。

禁止：水印、签名、边框、任何文字或形似文字的笔画、齿轮与电路板纹样、烟囱与烟雾、
盾牌、对勾叉号、锁与钥匙、传送带滚轮细节、人物。
