# 三道该拦住东西的门，钥匙挂在没人拿的墙上

3:2 横构图手绘笔记风示意图。主题：一条路上明明有三道门，可三道门都没关；
真正能拦住东西的那把尺子挂在右侧墙上，**没有人去拿**。画面不出现文字、字母、数字、伪文字、刻度数字。

构图：
1. 一条手绘地面横线从左贯穿到右（两端断开、略抖）。地面左侧一个小圆点（#FF6B6B，
   代表那份带额外字段的界面描述）正朝右滚。
2. 三道单扇拱门沿横线从左到右排开，**每道门都完全敞开**，门框厚、抖线描边（#2E3A47 填充 + #1F2429 描边）。
   三道门高度略微不齐（手工感，不复制粘贴）；门板各自朝外歪着，歪的角度不一样。
   每道门框上沿钉着一块**空白长方形小牌**（#9AA5B1 描边，牌面完全空白，不放任何字符）。
3. 小圆点已经穿过第一道与第二道门（在它身后各留一小段虚线轨迹），
   到第三道门前的地面上时，画成**一小片掉在地上的碎块**（两个极小的 #FF6B6B 点），
   表示"它过了门，但少了东西"。第三道门后是空白，不画任何东西。
4. 画面右侧墙上：一把直尺斜挂着（#9AA5B1，只画外形与几道等距短刻痕，**不写数字**），
   尺子挂在一枚钉子上但**没挂住**、下端往外翘；尺子下方地上放着一个空的小工具盒（盒盖翻开、里面空）。
   这是画面里唯一"能拦住什么"的东西，且没人拿。
