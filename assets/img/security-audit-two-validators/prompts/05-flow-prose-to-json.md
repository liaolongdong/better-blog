# 三张散文便签，改叠成一份能复查的台账

横向 3:2 手绘笔记流程图，从左到右三步，段间用单向细虚线箭头连接。

**第一步**：三张边缘不规则、叠放角度各不相同的散文便签纸（每张上面画四五行长短不齐的手绘波浪线，表示散文记录），最上面那张右下角画一个小墨点。

**第二步**：一只手绘的小漏斗（上宽下窄，轮廓轻抖），漏斗口上方两张便签正往下滑；漏斗颈部画一枚小齿轮形状，齿轮中心一个小圆点。

**第三步**：一叠整齐码放的格线卡片（四到五层，边线对齐），最上面一张卡片左上是同心弧线指纹印记，右侧三格各画一个小对勾，卡片右下角画一个手绘小圆章（章内不填任何字符）。

在整张图右下方，单独画一支平放的铅笔，笔尖朝左，指向那叠整齐卡片，表示「以后我自己也得按这个形状记」。

配色：奶油纸底 #FDF6E3；墨线 #1F2429；散文便签极淡灰蓝 #9AA5B1（低饱和，表示被淘汰的形态）；漏斗与小齿轮暗暖黄 #E8C86A；整齐卡片薄荷绿 #88D8B0；柔珊瑚 #FF6B6B 只用在齿轮与卡片之间那一小段箭头上。

风格：sketch-notes、平涂、线条轻抖、留白 ≥30%。

禁止：任何可读文字、字母、数字、单位、水印、签名、边框、写实人手（第三步只画卡片与铅笔，不要出现手）、3D 质感。
