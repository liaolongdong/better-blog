# 两个校验器各自举绿灯，中间那条对账线根本不存在

横向 3:2 手绘笔记示意图，画面严格左右对称两半，中间一条手绘的、明显断成三截的虚线。

**左半**：一台手绘的老式检票机/打孔器，机器上方一个小圆灯亮着（薄荷绿实心），机器左侧喂进一张小卡片，卡片上画一个同心弧线指纹印记，机器右侧吐出一枚画着对勾的小圆牌。

**右半**：一台手绘的立式秤/天平，秤盘上摊着一页格线账页（格子里画满小对勾），天平上方同样一个小圆灯亮着（薄荷绿实心），天平底座旁边画一把平放的小尺子。

**中间**：本应把两台机器连起来的那条线只画成三截断开的短虚线，断口处刻意留出两个明显缺口；在其中靠近下方的缺口里，一张薄纸片正斜着飘过去（表达「没被任何一方看见」），纸片旁边画一个手绘小问号轮廓，不填字。

配色：奶油纸底 #FDF6E3；墨线 #1F2429；薄荷绿 #88D8B0（两处绿灯）；灰蓝 #9AA5B1（右侧天平与尺子）；暗暖黄 #E8C86A（左侧小卡片与账页高亮）；柔珊瑚 #FF6B6B 仅用在那条断开虚线的一个断口描边上。
