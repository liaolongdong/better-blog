# 三根轴叉乘出一张派工单，末端是一张格线账页

横向 3:2 手绘笔记流程图，从左到右四段。

**第一段**：三张略微错开叠放的窄纸片，每张上面画两三条手绘短横线（表示三个独立维度：入口面、信任边界、攻击类别），三张纸片右端各伸出一条细线，三条细线在中间汇成一个手绘的叉号形状（表示叉乘），叉号线条轻抖、粗细不匀。

**第二段**：汇线之后是一枚竖版小卡片（派工单），卡片顶部一条实心墨线，下面三行短横线，右下角画一个手绘小圆勾选圈。

**第三段**：三个极简化的小人形剪影（无五官、无衣着细节，只有一个头加一个方身），每个头顶挂一盏小灯（一盏薄荷绿、一盏灰蓝、一盏暗暖黄，表示并发派工），三个小剪影各自朝向一张小纸片做「查看」姿势，手臂画成一条弯线即可。

**第四段**：一张摊开的格线账页（ledger 隐喻），格子里画满小对勾，其中两格留白（表示 planned 与 covered 两种形状的差异）；账页右下方画一支平放的铅笔。

配色：奶油纸底 #FDF6E3；墨线 #1F2429；暗暖黄 #E8C86A；灰蓝 #9AA5B1；薄荷绿 #88D8B0；柔珊瑚 #FF6B6B 只用在中央叉号的一处描边。

风格：sketch-notes、平涂、线条轻抖、段与段之间用细虚线箭头连接、留白 ≥30%。

禁止：任何可读文字、字母、数字、百分比、单位、水印、签名、边框、写实人物面孔、3D 质感。
