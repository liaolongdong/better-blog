# 一条横轴上的四段时间：前三段挤在左端一小截，第四段单独拉开一大片

16:9 手绘笔记风时间线。主题：**同一件事的四个节点，间隔长短差得离谱**——发现、报警、
有人接手这三步挤在最左边一小段里，最后一步"停掉"却被拉到最右边，中间是一大片空白。
画面不出现任何文字、字母、数字、伪文字、刻度数值、勾叉符号。

主轴：一条横向的手绘长线，从左至右贯穿画面，线本身近黑 #1F2429、线条发抖、粗细不匀，
右端不画箭头，只让线自己收住。线的下方什么都不填，整幅图靠这条线组织。

四个节点（关键在这四者的**间距分布**）：
1. 最左端起算约 4% 处：第一枚记号——一根短竖签插在轴上，竖签顶端是一个**小实心圆点**，
   圆点用暗金 #E8C77A（这是全图第一个亮点，代表"这一步真的发生了"）。
2. 约 10% 处：第二枚记号——同样的短竖签，顶端换成一个**空心的小铃铛轮廓**（灰蓝 #9AA5B1 描边、
   内部留空，不画铃舌以外的细节）。
3. 约 15% 处：第三枚记号——短竖签，顶端是一个**无脸的小人上半身剪影**（近黑 #1F2429，
   只有头与肩，肩上落一道 #9AA5B1 的边光）。
   这三枚记号**必须挤在一起**，签与签之间的水平间距小到人一眼看出"这三步几乎连着发生"。
4. 约 88% 处：第四枚记号——一根**明显更粗、更长**的竖签，顶端不是圆点、不是铃铛、不是人，
   而是一道**横向的短粗线**（像被人一笔画断的收笔），近黑 #1F2429，粗度是前三根的约两倍。

空白带（本图的表达重点）：从第三枚记号到第四枚记号之间的那一大段轴，
上方画**一段水平的双向括号**（大括号朝上），括号两端各垂下一条极细的引导虚线，
分别落在第三、第四枚记号的根部；括号线用灰蓝 #9AA5B1、画得比主轴细。
括号与轴围成的这块长方形区域**刻意留白**，留白占全图面积约三成——
这块空就是"这段时间里没人把它停下来"。
留白区域里撒**两三个极淡的、不成形的点**（#2E3A47，几乎看不见），表示这段时间不是空的、
是发生了什么但没被处理；禁止在这里画时钟、沙漏、进度条、齿轮。

轴下方：只画**一道淡淡的落影**（#2E3A47 的横向短抹，跟随主轴抖动），不给任何文字标注。

光线：整体平涂暗色，无光源方向；只有第一枚记号的暗金圆点带一圈极小的暖光晕。

配色：主背景 #1B2430；主轴与剪影 #1F2429；辅助描边 #9AA5B1；唯一亮点 #E8C77A；
留白区不填色。奶油纸底 #FDF6E3 只在铃铛内部与括号端点各点一下，全图不超过两处。

风格：hand-drawn sketch-notes，平涂，抖线，留白 ≥35%。

禁止：水印、签名、完整边框、任何可读文字与数字、刻度值、时钟、沙漏、盾牌、警铃特写、
红绿灯、进度条、对勾与叉、图表坐标轴标签、机器人、大脑、齿轮。
