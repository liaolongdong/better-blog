# 同一个门洞出来的两条走廊：一条走到尽头被门槛石绊住，一条半途被卷帘切断

16:9 手绘笔记风概念图。主题：同一个接口，带不带过滤条件走的是两条不同的天花板——
一条是老路，尽头有块石头绊你；一条是新路，走到一半帘子就放下来了，帘子后面的没人替你数。
画面不出现任何文字、字母、数字、伪文字、勾叉符号。

构图：画面左侧一道拱形门洞（与封面同一道门，保持视觉连续：门框灰蓝 #9AA5B1 描边 +
近黑 #1F2429 双线，门洞内填深墨蓝 #2E3A47）。门洞右侧地面一个起点圆点，从这一点引出
**上下两条走廊**，两条走廊的地面石板数量明显不等：上条 8 块、下条 4 块。

上走廊（长、通到底）：石板等距铺到画面最右端，右端画**一块断成两截的门槛石**横在路上，
断口两道锯齿线，石头右侧洒三小块碎屑（碎屑用暗红 #FF6B6B，本图唯一红点）。
走廊尽头不画出口、不画光，只有一条收边短竖线。石板线条要抖、间距故意不完全一致。

下走廊（短、被帘子挡）：走到画面中段，从上方垂下一道卷帘——横向 5 道条纹（#9AA5B1），
帘身填奶油纸底 #FDF6E3 压暗一档，帘底呈轻微弧形，两侧各一条短竖线当导轨。
关键：**卷帘没有落地**，帘底与地面之间留一条明显的缝；缝下面挤出半截没走完的队伍——
三个无脸火柴人剪影（近黑 #1F2429）加两个小方块箱子，队尾被画面右边缘切断。
缝隙处画两道极短横线，表示"还在往外漏"。

两条走廊的对照强调：从上走廊的门槛石、下走廊的卷帘底部，各引出一条极细的手绘虚线（#9AA5B1），
两条虚线向下汇到画面底部同一点——那一点画一枚被丢在地上的小圆牌（无字、纯色），
表示"两处到此为止，但停的方式完全不同"。

次要细节：下走廊卷帘左侧的地面上，画一只翻倒的小木凳（四条腿朝上），与封面系列保持同一手势语言。

配色：底 #FDF6E3 带细纸纹；门洞 #9AA5B1/#1F2429；石板 #FDF6E3 压暗两档描 #1F2429；
门槛石 #2E3A47；卷帘 #FDF6E3 压暗 + #9AA5B1 条纹；虚线 #9AA5B1；碎屑暗红 #FF6B6B；
