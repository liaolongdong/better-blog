# 04 comparison：同一个 flag 加与不加

## 说明
同一张本地页面、同一个 WebMCP 工具，chrome-devtools-mcp 不加
`--enable-features=WebMCP` 时列出来是空的；加上之后工具出现、能被调用、
表单被填上。而这条 Chrome 侧要求只写在 `--help` 里。

## Composition
画面正中一条竖虚线，把画分成左右两半，两半画的是同一台浏览器窗口和同一个
小机器人（工具调用方）。
- 左半（未加 flag）：浏览器窗口里画一个表单，表单上三行输入框全是空的，
  输入框上各画一个小叉；窗口下方一个手绘列表框，框里一片空白，只有一条
  虚线和末尾一个小圆点，表示"返回空列表"；小机器人站在列表框旁，头上一个
  问号。整体线条偏灰蓝。
- 右半（加了 flag）：同一个窗口，三行输入框里有两行画上了对勾，第三行画着
  正在被填的笔迹；下方同一个列表框里出现三个整齐的小方块；小机器人举手做
  "完成"的姿势，头上一颗对勾。整体线条偏薄荷绿，加一点暖黄高光。
- 两半之间的虚线上方：画一个小小的开关（拨动开关），开关拨向右侧，开关上
  方画一条极短的引线指向画面底部那条终端行。
- 画面底部：一条手绘的终端提示行，只画一个大于号和一条横线，横线右侧留空。

## SYMBOLS ONLY
画面里只允许出现一个数字和一个符号，且必须正确：
- "3"（右半列表框里的三个小方块旁，薄荷绿色）
- "?"（左半机器人头顶，柔珊瑚色）
除此之外不得出现任何文字：不写英文单词、不写汉字、不写命令行参数、不写伪文字。
"这条要求只写在 --help 里"这个意思靠底部那条只有大于号的终端行表达。

## COLORS
奶油纸底 #FDF6E3；墨线 #1F2429；左半整体降饱和用灰蓝 #9AA5B1；
右半用薄荷绿 #88D8B0 与暖黄 #FFD93D；开关与叉号用柔珊瑚 #FF6B6B。

## STYLE
sketch-notes 手绘笔记风，左右严格同构（同一个窗口、同一个机器人，只差状态），
线条轻微抖动，平涂无渐变，无 3D，无人物脸部细节，留白 35%。

## HARD CONSTRAINTS
禁止水印、签名、边框、logo；不得出现任何真实浏览器 logo 或品牌标识；
除 3 和 ? 之外，一个字母和一个汉字都不许出现。
