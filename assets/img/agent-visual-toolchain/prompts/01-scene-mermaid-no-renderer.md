# 01 scene：一段没人渲染的 mermaid

## 说明（给读者看的画面）
博客发布链路把 Markdown 交给 Jekyll，中间那段 mermaid 代码块没有渲染器，
于是读者看到的是一行行源码文本，而不是一张图。

## Composition
一张手绘画纸分上下两层。
- 上层：一台简化的小浏览器窗口，窗口里画着一张本该出现的流程图（几个圆角
  方框 + 箭头，用薄荷绿标出），方框上方盖着一个半透明的、被撕掉的纸片，
  纸片形状就是那张流程图，表示"图被撕走了"。
- 下层：同一块位置换成五行整齐的等宽文本线条（不写真实字符，用短横线和竖线
  表示代码行），左侧一个小小的问号和一条下划线。
- 右侧：一支放大镜，放大镜里能看到横线，放大镜外什么都看不清。
- 底部：一条极细的传送带，从左到右，四个小图标依次是"文档 → 齿轮 → 齿轮 →
  浏览器"，中间两个齿轮之间的传送带上有一个小缺口，示意渲染器缺失。

## NO TEXT
全图不得出现任何可读文字、字母、数字、汉字，也不得出现形似文字的乱码笔画。
"源码文本"这一层用抽象记号表达：五行长短不一的水平短横线，每行开头缩进不同，
个别行前面画一个小问号和一条下划线；放大镜里同样只画横线，不画字符。
ABSOLUTELY NO TEXT: no letters, no digits, no Chinese characters, no pseudo-glyphs.

## COLORS
奶油纸底 #FDF6E3；近黑墨线 #1F2429；被撕掉的图用薄荷绿 #88D8B0；
缺口与问号用柔珊瑚 #FF6B6B；齿轮用灰蓝 #9AA5B1；标题区暖黄 #FFD93D 微光。

## STYLE
sketch-notes 手绘笔记风，线条有轻微抖动，平涂无渐变，无 3D，无人物脸部细节，
留白 40%。

## HARD CONSTRAINTS
禁止水印、签名、logo、边框；画面里一个字符都不许出现；
不得出现可识别的产品图标。
