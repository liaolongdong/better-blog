# 03 flowchart：装完 374MB，它又去 clone 了一遍

## 说明
HyperFrames 用 npm 装完 374MB 之后，`init` 仍然自己跑去 GitHub clone 整个仓库
去取 AI skill；网络在半路断掉，9 个 skill 没装上，而命令的退出码是 0。

## Composition
一条从左到右的手绘流程图，四段，用箭头串起来，每段一个圆角方框。
- 方框 1：一个小盒子往里倒沙子（表示 npm install），盒子上堆一座小沙丘，
  沙丘旁边画一个刻度盘，指针打满。
- 方框 2：一个终端小窗口，里面两行横线代表命令输出，窗口右下角画一个
  小小的"0"，用暖黄圈住，表示退出码 0。
- 方框 3：一条弯弯曲曲的长途箭头，从方框 2 出发绕到画面右上角的一个云朵
  （云朵里画一个普通的方形包裹），再从云朵绕回来——表达"已经
  装完了还要再下载一次整仓"。这条长箭头在中间被一把小剪刀剪断，断口两半
  分开，断口处用柔珊瑚色。
- 方框 4：一个空托盘，托盘上方飘着 9 个小方块，每个小方块上打一个叉，
  表示"9 个 skill 仍然 missing"。
- 底部：一条细细的时间轴，末端画一个沙漏，沙漏旁挂一个小标签。

## DIGITS ONLY
画面里只允许出现四个手写阿拉伯数字，且必须逐字正确：
- "374"（画在方框 1 的沙丘上）
- "0"（画在方框 2 的黄圈里，单独一个字符）
- "9"（画在方框 4 上方，字号最大）
- "98"（画在沙漏旁边）
除此之外不得出现任何文字：不写英文单词、不写汉字、不写单位字母、不写伪文字。
"MB""秒""skill"这些单位一律不写，靠画面本身表达。

## COLORS
奶油纸底 #FDF6E3；墨线 #1F2429；断口与叉号用柔珊瑚 #FF6B6B；
通过的段落用薄荷绿 #88D8B0；退出码 0 用暖黄 #FFD93D；云朵与箭头用灰蓝 #9AA5B1。

## STYLE
sketch-notes 手绘笔记风，箭头有轻微抖动，平涂无渐变，无 3D，无人物，留白 35%。

## HARD CONSTRAINTS
禁止水印、签名、边框、logo；不得出现任何真实品牌标识，云朵里只画一个普通的
方形包裹，不得出现猫脸、猫爪、octocat 或任何带品牌特征的剪影；
除 374 / 0 / 9 / 98 四个数字外，一个字母和一个汉字都不许出现。
