# 一个字段的旅程：四站全路过，最后一站没有接管

16:9 手绘笔记风轨迹图。主题：一个声明字段从配置文件出发，被存进缓存、被数进表格列、
被打印到终端输出，最后停在一扇"该接管道"的门前面——门后面是空的。画面不出现任何文字、
字母、数字、代码符号。

构图：一条从左到右的手绘虚线轨迹（灰蓝 #9AA5B1，线段短、间隔均匀），途中经过四个小站点，
轨迹末端停在最右侧一扇门前。轨迹上每隔一段画一个朝右的小箭头，共 4 个。

移动的"主角"：一个小的暖黄 #FFD93D 填充 + 近黑 #1F2429 描边的**竖向小卡片**（代表那个字段），
它在第一站出现一次，之后轨迹上只留下它的浅黄脚印（同形状、颜色更淡），到门前就停止。

四个站点（从左到右，形状各不相同，避免画成一样的方框）：
1. **出发点**：一张左上角折起的纸片，纸面只有三道短横杠（不构成字），纸片外侧套一条手绘的
   虚线包围圈，表示"声明就写在这里"。包围圈 #9AA5B1。
2. **缓存站**：一个矮胖的圆柱体（数据库/缓存的经典手绘形状），深墨蓝 #2E3A47 填充 + 描边近黑，
   顶面画两道椭圆高光；小卡片的脚印进入圆柱侧面。
3. **表格站**：一个 3 列 2 行的极小手绘表格（只用直线画格，格子里是空的，不写字），
   其中第二列整列描成薄荷绿 #88D8B0（表示"这一列就是数出来的那个数"）；
   表格右上方画一个小小的向上抬升的短箭头，暗示"数值往上冒了一格"。
4. **输出站**：一个小终端窗口（矩形 + 顶边一条粗横杠代表标题栏），窗口内画三行长度不一的
   短横杠（纯墨线，不构成文字），最后一行那条横杠末端画一个停住的实心小点。

终点（本图重点）：轨迹末端是一扇只有门框和门板、门板下没有任何管道穿过地板的门。
门板薄荷绿 #88D8B0 描边、门内完全是比底色更亮的空白（一片什么都没有，不画房间、不画光），
门槛下方有两条断开的锯齿短线（暗红 #FF6B6B），强调"这里本该接出一根管子"。
小卡片的最后一个脚印正好停在门前半步，没有进门。

配色：底 #FDF6E3 带细纸纹；轨迹与包围圈 #9AA5B1；圆柱 #2E3A47；主角卡片与脚印 #FFD93D；
表格高亮列与门框 #88D8B0；门下断口 #FF6B6B。

风格：sketch-notes，平涂，轻微抖线，留白 ≥30%，四个站点大小相近（不抢戏）。

禁止：水印、签名、边框、任何可读文字与数字、齿轮、机器人、放大镜、锁、钥匙。
