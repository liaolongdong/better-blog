# Cover: 三份并排的预装清单，只有左边那份下面接着真的管道

16:9 横构图，手绘笔记风 + 深色底，画面里**不允许出现任何可读文字、字母、数字、伪文字、
横线占位符、勾选框里的符号**。整幅图只有三件事：三张清单、三条管子、一层地板。

主体：画面中上部并排悬着三张竖向的长方形纸片（代表"预装清单"），大小完全一致，
纸面是暖黄 #FFD93D 的暗调版本 #E8C77A 填充 + 近黑 #1F2429 描边，纸面上只有三道
**很短的横杠**（每张纸三道，纯墨线笔画，不构成任何字），纸角微微上卷。

管子（关键，决定这张图的意思）：

  与纸底两端都**画成实连接**，管身上有两道接缝。管道本体：灰蓝 #9AA5B1 描边 + 深墨蓝 #2E3A47 填充。
- 中间与右边那张纸的正下方各垂下一条管道，但两条都在**完全相同的高度齐齐截断**：
  断口画成锯齿状的空心截面（露出纸一样的白），断口下方到地板之间是**空的一段距离**，
  地板上对应位置只有两块比底色稍亮的浅矩形压痕（表示"这里本来该有东西"）。

地板：画面底部一条横向的手绘地板线，从左贯到右，地板上有三条很浅的木纹斜线；
只有左边那一处有盒子，其余两处空着。
