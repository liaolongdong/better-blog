# 插图 02: 三枚挂钩钉在同一面墙上，只有中间那枚还连着电线，左右两枚的线头垂着没接

横版 16:9，手绘笔记风（sketch-notes），奶油纸底 #FDF6E3，线条为手绘不规则笔触（近黑 #1F2429 描边），
**画面里绝对不允许出现任何可读文字、字母、数字、英文单词、伪文字、乱码字形、logo、水印、签名、边框标签**。
三枚钩下方各有一块**空白小牌**，牌上只画抽象符号（一个点 / 两个点 / 一条斜杠），不写任何形。

一张图讲一件事：**三个入口里只剩一个还接得上**。

构图（严格三等分栅格，留白充足，元素之间至少留出 12% 宽的空隙）：

- **背景**：一整面浅奶油纸墙 #FDF6E3，占满画布，边缘不做相框。墙面顶部横着一条
  极淡的手绘水平线（灰蓝 #9AA5B1，20% 透明），像笔记本上的页眉线，线上什么都不写。
- **左枚钩**：粗 L 形钩，描边近黑 #1F2429，钩身填淡灰蓝 #C8D0D8（**明显是灰的、没电的**）。
  从钩根引出一段电线，线在离钩约 15% 处**断掉**，断口画成两小卷裸露的线头，
  线头颜色用暗灰 #9AA5B1，下方垂着、轻微晃动的两道短弧线表示它悬着没接东西。
  钩下小牌：**只画一条斜杠 `/`**（近黑，笔触略歪）。
- **中枚钩（唯一活着的）**：同一形状但**更大一号**，钩身填暗金 #E8C76A（全图唯一暖色，
  视觉重心）。从钩根引出一条**绷直的暗金电缆**，一路向下接到一只**无脸小机器盒子**：
  圆角矩形机身 + 一根短天线，近黑描边、机身填淡灰蓝，机身上不画字符不画屏幕内容。
  电缆中段画两个小"通电"的节奏记号：两条极短的平行斜刺（不是闪电符号，只是两道小划）。
  钩下小牌：**只画一个实心圆点**（近黑，直径约牌宽的 1/4）。
- **右枚钩**：与左枚同尺寸、同样灰（#C8D0D8），电线同样**断口悬垂**，但断口画在更靠右的位置，
  与左枚形成镜像但不完全重复（避免看起来是复制粘贴）。钩下小牌：**只画两个实心圆点**，
  两点间距略宽。
- **地面**：三只钩下方不必各自落地；整幅图底部画**一条手绘地平线**，水平略波浪，
  中间机器盒子稳稳坐在盒子上方那块地面上，地面以下留 8% 空白。

明暗与情绪：活的只有中间，其余两处不是"坏掉"而是"没接"。整幅图不画任何人、不画手、
不画表情、不画箭头指向、不画任何红色警示。

对比强化：三枚钩的**牌上符号必须各不相同**（斜杠 / 一个点 / 两个点），让读者一眼分出
"这是三个不同的东西"，而它们钩子的形状完全一样——这个"形状一样、通断不一样"是全图要点。
