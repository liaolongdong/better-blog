# 倒着读的四分钟与七天

16:9 手绘笔记风时间线，**从右往左读**（用箭头明示倒序）。主题：一次合并只活了三十五分钟就被
摘掉清单条目，五天之后目录才被删干净；三段窗口的"窄"和"宽"要用图形间距表达。画面不出现文字与数字。

构图：一条手绘水平墨线横贯中部，线上挂 4 个标记（从右到左排列，右侧为时间起点）：

1. 右端：一枚实心小圆点 + 一条向上翘起的短旗线（一次上架合并进 main）。
2. 往左一小段（间距明显很窄）：一把张开的剪刀，剪口正好咬住一条细纸带，
   纸带被剪成两段、右段向下垂落（从清单里摘掉条目）。剪刀 #FF6B6B 描边。
3. 再往左一大段（间距是第 2 段的好几倍）：一只空纸箱斜倒在地、箱口朝上（目录被删）。
   箱体 #2E3A47 填充。
4. 左端：一枚空心小圆点，圆点右侧一点立着一块只画了轮廓的空白长条牌（表格里的行还在）。
   长条牌 #FFD93D 描边。

倒序指示：在这条水平线的**下方**画一条带单个大箭头的长细线，箭头明确指向左，
箭杆中点上方画一个回头看的简笔画小眼睛（灰蓝 #9AA5B1）。

两段窗口的表达：第 1、2 个标记之间涂一段柔珊瑚 #FF6B6B 的短线段（窄窗口）；
第 2、3 个标记之间用一条带双箭头的细括线在上方整体括起来，括线中间悬一朵很小的乌云（宽窗口）。

配色：底 #FDF6E3 细纸纹；主墨线 #1F2429；剪刀与窄窗口段 #FF6B6B；
