# 五道门，每道漏掉同一样东西

16:9 手绘笔记风示意图。主题：一个坏掉的配置文件要从仓库出去，要连过五道关，
每道关都各查各的，于是**同一个东西**从五道关之间的缝里一路穿过去。画面不出现文字、字母、数字。

构图：从左到右排五道**形状各不相同**的门（不用一模一样的门复制五次，避免数量被画错），
每道门只画门框与半开的门板，门板之间留一条明显的地面通道。

1. 第一道：拱形门，门框上挂一面小圆镜（代表"只照某几类文件"）；镜面上有一块方形黑影（照不到的那类）。
2. 第二道：方形门框，框内斜挂一把只有两根齿的梳子（代表"清单式检查"），齿间空隙很大。
3. 第三道：门框里画一排短竖栅，栅格右侧留一整段空白缺口（覆盖范围缺一块）。
4. 第四道：门上挂一把钥匙，但钥匙孔形状与穿过去的东西不匹配（孔是圆的，来的是方的）。
5. 第五道：门槛断了一截（代表跑到这里就停了），断口用两段错开的粗线表示。

贯穿物：一个小小的、被撕开一角的**信封形**方块（代表那份坏配置），从画面最左侧出发，
沿地面一条虚线轨迹一路穿过五道门之间的缝隙，最后停在最右侧、虚线末端画一个空心小圈。
信封描边 #FF6B6B，穿行的虚线轨迹 #9AA5B1，每道门之间的空隙处画一小段向上的浅弧（它没被拦下）。

配色：底 #FDF6E3 细纸纹；五道门门框 #2E3A47 填充 + #1F2429 抖线描边；
小圆镜 #88D8B0、梳子 #9AA5B1、栅格 #9AA5B1、钥匙 #FFD93D、断门槛 #FF6B6B；
信封 #FF6B6B 描边、内部留白。

风格：sketch-notes，平涂，轻微抖动线条，留白 ≥30%，五道门高度不完全一致（人为不齐）。

禁止：水印、签名、边框、任何可读文字与编号、盾牌、对勾与叉号、进度条、任何数字标注。
