# 按文件清单做减法的三刀

16:9 手绘笔记风流程/减法图。主题：一次上架铺开的文件堆，被后面两次下架**照文件清单**逐块搬走，
清单里没有的那一块就留在原地发光。画面不出现任何文字、字母、数字。

构图：横向分三段，用一条很细的灰蓝 #9AA5B1 水平箭头从左贯到右，把三段串起来。

左段：一堆紧密拼贴的小方块（用"一簇"表达数量多，画 9 块即可，不要画成可数的整齐行列），
每块是深墨蓝 #1F2429 填充 + 灰蓝描边；这一簇整体外面套一条手绘的虚线包围圈（表示"一次提交铺开的范围"）。

中段：两把并排的铲子/搬运手从这簇方块里往外取东西——上面一把抓走一小叠（画 6 块），
下面一把抓走一条细长条（画 1 块细条）。被取走的路径用两条短弧线的运动轨迹（开口朝右）表示。
两把工具本身：一把薄荷绿 #88D8B0 描边，一把灰蓝 #9AA5B1 描边。

右段：剩下**唯一**一块方块立在原地，位置比左段那簇略低一点，这块是暖黄 #FFD93D 填充 +
近黑 #1F2429 描边，四周画 6 条短放射线表示"还在被看见"；它旁边留一块浅灰蓝的矩形痕迹，
表示同簇其他位置已经空了。

关键细节：从左段到右段，中间那把"细长条"形状的方块与右段那块立着的方块**形状完全一样**（同一物），
强调"它没被搬走"。

配色：底 #FDF6E3 带细纸纹；方块 #1F2429/#2E3A47；轨迹与包围圈 #9AA5B1；
两把工具 #88D8B0 与 #9AA5B1；幸存块 #FFD93D；一处暗红 #FF6B6B 只用来画包围圈上一个被剪断的缺口。

风格：sketch-notes，平涂，轻微抖线，留白 ≥30%。

禁止：水印、签名、边框、任何可读文字与数字、加减乘除符号、钟表、可数的整齐方阵（避免数量画错）。
