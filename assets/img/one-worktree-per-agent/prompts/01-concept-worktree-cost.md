# 五个工作树，五份完整代码，一个共享底仓

横向 16:9 手绘笔记风概念图。主题：多开一棵工作树，磁盘上就多一整份 checkout，
共享的只有底仓那一小块。

画面主体：横向并排五个大小一致的手绘小工作区（每个画成一个简笔工位：一块斜板
加两条腿，不画真实的桌椅细节），五个工位下方各自压着一叠**厚度完全相同**的
纸块（每叠画 6~7 层横线表示一叠），五叠纸并排形成一排整齐的"厚度墙"。

画面上方中间只画**一个**手绘的圆筒形容器（共享底仓），从它身上垂下五根细绳，
分别系到五个工位上——五根绳、一个容器，视觉上明确"共享的只有一处"。

在最右侧那一叠纸旁边，画一个手绘的双向竖直箭头（跨整叠纸的高度），
箭头旁不写任何数字或单位；箭头末端画一个极小的实心圆点作为终点标记。

左下角画一个被推出去的小人剪影（只有轮廓），站在五叠纸的阴影外。

配色：奶油纸底 #FDF6E3；墨线 #1F2429；工位与纸叠灰蓝 #9AA5B1 + 暗暖黄 #E8C86A；
共享容器与五根绳薄荷绿 #88D8B0；竖直双向箭头柔珊瑚 #FF6B6B。

风格：sketch-notes，平涂，线条轻抖，留白 ≥30%。

禁止：水印、签名、边框、可读文字、任何数字或倍数标注、真实 logo、
五行表格或图表坐标轴。
