# Cover: 三家并行工作区，一家在门口就被拒

16:9 横构图，手绘笔记风 + 深色底，画面里**不允许出现任何可读文字、字母、数字、伪文字**。

主体：画面下三分之二并排站着三间极简的手绘小木屋（并不等宽，中间那间略小、
最右那间只画到一半，像没画完），每间屋子底下都压着**一整叠**厚厚的纸张块面
（表达"每棵树各一份完整 checkout"），三叠纸的厚度肉眼一致。三间屋子的屋顶
各自垂下一根细绳，三根绳在画面上方汇到同一个手绘的圆筒形容器（共享的仓库底仓），
容器只画一个，位置偏右上。

最左边那间屋子的门上挂一把**扣死的**粗重挂锁，锁身上画一条粗的斜杠（拒绝），
锁下方垂着一条空白的小布条（布条上不得有任何字符）；另外两间屋子的门是半开或
画不到底的，没有锁。

一个极小的人形剪影站在最左边那间屋子门前，背对观众，离门两步远，
不接触门，没有脸、没有手指细节。

光线：从共享容器向外发暖光，三间屋子与三叠纸处于偏暗的剪影调子里，
锁与斜杠是画面最亮处。

绳索与共享容器用薄荷绿 #88D8B0，挂锁与斜杠用柔珊瑚 #FF6B6B。

风格：sketch-notes 手绘笔记，平涂无渐变块面，轻微抖动线条，留白 ≥35%。
