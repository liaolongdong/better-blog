# 账面上报了五份，真实水位只涨了一点

横向 16:9 手绘笔记风对比小图，左右两栏，中间用一条手绘的竖直虚线隔开。

**左栏**：五份完整的纸叠竖向等高等宽并排立着（每叠画 6~7 层横线），
下方画一台手绘的老式天平/秤盘，五叠纸全放在同一个秤盘上，秤盘被压得明显偏低，
指针大幅偏向一侧（不写刻度数字）。

**右栏**：一只大号手绘水箱/量杯，杯壁上有四条极淡的水平刻度线（无数字）。
杯里的水位只到**第一条刻度线再往上一点点**的位置（表达"真实只涨了一点"），
水面画成轻抖的波浪线，水体用半透明薄荷绿平涂。
水箱底部落着四片薄薄的纸片残角（表达"只有头一份是完整拷贝，其余几乎不占"），
残角旁边画一个手绘的小斜杠符号，不写字。

两栏之间画一个从左指向右的**手绘细箭头**（单向），箭头穿过竖直虚线，
箭头上不挂任何文字。

配色：奶油纸底 #FDF6E3；墨线 #1F2429；五叠纸暗暖黄 #E8C86A；
天平与水箱灰蓝 #9AA5B1；水体薄荷绿 #88D8B0；
左栏秤盘与右栏水位线各用一处柔珊瑚 #FF6B6B 做强调点。

风格：sketch-notes，平涂，线条轻抖，留白 ≥30%。
