# Cover: 一道门上挂着两色光

16:9 横构图，手绘笔记风 + 深色底，画面里**不允许出现任何可读文字、字母、数字、伪文字**。
构图刻意只用"一个"主体，不画成排的门（成排的东西会被画错数量）。

主体：画面中央偏右一道手绘拱门，正面视角，门板半开。门缝里漏出的光被分成两半——
左半边是暗红（#FF6B6B），右半边是薄荷绿（#88D8B0），两色在门缝中线处直接相邻，
不渐变、不混合。门板正中横着一条下垂的锁链和一把上了锁的挂锁（锁在红那一侧）。
门框用抖动的墨线勾，墙是大面积深墨蓝 #1B2430，占画面三分之二以上。

画面左侧三分之一，站着一个很小的人，背对观众，没有脸，只画轮廓，
手里举着一张只有四行横线的纸（横线代表配置文件，不得写成可辨认字符）。
人物脚边的地面上，画一枚被一条斜线划掉的小钥匙（只一枚，不许多画）。

画面右上方：三条细的椭圆轨道线从画外绕进来，汇成交叉点，
交叉点上停着一枚正在发光的暖黄小方块（#FFD93D，代表并发组"同一时刻只放行一个"）。

光线：门缝的两色光在门前地面拉出两小片光斑，一红一绿；人物处于剪影状态。

配色：外围留白用奶油纸底 #FDF6E3 的细纹理；主画面深墨蓝 #1B2430；
门框近黑 #1F2429 描边 + 灰蓝 #9AA5B1 填充；红光 #FF6B6B；绿光 #88D8B0；
方块与划掉的钥匙描边 #FFD93D。

风格：sketch-notes 手绘笔记，平涂无渐变块面，轻微抖动线条，留白 ≥30%。

硬性禁止：水印、签名、logo、印章、边框、角标、任何文字或形似文字的笔画、
可识别的产品图标、成排重复的门（数量会画错）、多把钥匙。
