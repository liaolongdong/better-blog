# 校验发生在版本切换之前

横向 16:9 手绘笔记风流程图。主题：同一个 pin，两条命令走到的深度不一样——
读取和校验 workspace 文件这一步，发生在"切换到被钉住的版本"之前。

画面自左向右四站，用带小箭头的横线连成一条主流程：

1. 一张四行横线的纸（workspace 配置文件，横线上有一个用墨点画的小星号，
   标示"其中一行是没人认识的新字段"）。
2. 一台手绘的小天平（当前进程自己的字段表），天平左盘放着那枚星号、
   明显下沉；右盘空着。
3. 一个分叉：横线在这里分成上下两路。
   上路走到底是一道门，门前画一枚实心圆 + 一个向下的短箭头落到地面（失败即终止）；
   下路绕过天平直接连到第二道门，门前画一枚空心圆 + 一支继续向右的小箭头。
4. 两路在画面最右侧汇成一个很小的台子（真正执行的版本），台子上方飘着一个
   只有轮廓的小旗。

关键表达：那枚星号在第 2 站就被称出来了，所以它到不了第 4 站——
上路那条线画得短、断在半路，断口用两三个小叉号标出。

配色：底 #FDF6E3；墨线 #1F2429；天平与两扇门 #9AA5B1；
上路断口和实心圆 #FF6B6B；下路空心圆 #88D8B0；纸上的星号与最右小旗 #FFD93D。

风格：sketch-notes，平涂无渐变，线条轻抖，留白 ≥30%。
