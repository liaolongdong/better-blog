# 同一行拼错，两条分开的路

横向 16:9 手绘笔记风对比图。主题：同一处大小写拼错的字段名，左边那一版硬拦下来
并且额外给了一句"猜你想写什么"，右边那一版只亮黄灯然后继续安装。

画面正中偏上：一行手绘的代码行（一段短横线代表键名，末尾跟着两个小方括号），
其中第三个字符的位置被画成一个"翻转的、明显倒过来的小符号"，符号右侧紧跟一枚
小星号——表达"这里拼错了"。这一行往下伸出两支对称的手绘箭头，左branch与右branch。

左路（拦下）：
1. 一盏圆形信号灯，涂实心红。
2. 信号灯下方是一个矩形小牌，牌里画三条长度不等的短横线（两行错误信息 +
   一行"可用字段列表"的意象）。
3. 小牌右侧画一个放大镜，放大镜镜片里画一条最短的横线（那句额外的提示），
   放大镜手柄指向那枚倒过来的符号。
4. 路末端：地面画一道粗的断路坎，坎上两个小叉号。

右路（放行）：
1. 一盏圆形信号灯，涂空心黄（描边 #FFD93D、内填白）。
2. 信号灯下方是一个矩形小牌，牌里只有两条短横线（比左边少一条）。
3. 小牌右侧画一只摊开的手掌轮廓，掌心上一片叶子正在飘落（"不认识、已忽略"）。
4. 路末端：一个大的对勾，对勾下面画一小段完整不断开的地面。

两路的最末端用一条极细的虚线在底部横连，暗示"同一个输入"。

配色：底 #FDF6E3；墨线 #1F2429；左路红牌与叉号 #FF6B6B；左路放大镜 #9AA5B1；
右路灯泡描边与落叶 #FFD93D；右路对勾与摊开的手掌 #88D8B0。

风格：sketch-notes，平涂，左右重量对称但细节不等（左边多一个放大镜与一行），
留白 ≥30%。

禁止：水印、签名、边框、可读文字、字母、数字、伪文字、任何 logo。
