# 七道门：三道挂红牌，四道放行

横向 16:9 手绘笔记风。主题：同一份五行配置、同一条安装命令，七个版本里三个
硬失败、四个通过，失败的三个横跨两条大版本线。

画面主体：七个手绘门框横向等距排开（高度一致、宽度略不同、线条抖动）。
从左到右的门内状态严格按下表画，不许调换顺序：

- 第 1 道：敞着，门内空心圆（连一句警告都没有）
- 第 2 道：挂着下垂锁链 + 门板中央一枚实心红牌
- 第 3 道：同第 2 道（锁链 + 红牌）
- 第 4 道：敞着，空心圆，门口地面上画一小面飘着的小旗（它是这四个里唯一会
  额外"猜你想写什么"的那一个——用小旗表示多出来的那一句，不要写字）
- 第 5 道：红牌，但门板上多画一小块撕掉的纸角（它报的是另一类错误码）
- 第 6 道：敞着，空心圆
- 第 7 道：敞着，空心圆，门框外侧画一个很小的对勾

七道门下方有一条横贯的浅底线（基准线）。底线正下方，用两条很短的手绘括线
把红牌所在的第 2、3 道括成一组，第 5 道单独括一组——表达"红牌不是连续的一段"。

画面最右侧、七道门之外，画一个极小的人，抬手挠头，手里没有拿东西。

配色：底 #FDF6E3；门框 #1F2429 描边 + #9AA5B1 填充；红牌与锁链 #FF6B6B；
空心圆与对勾 #88D8B0；小旗与撕掉的纸角 #FFD93D。

风格：sketch-notes，平涂，留白 ≥30%。

禁止：水印、签名、边框、可读文字、字母、数字、版本号、伪文字、任何 logo。
