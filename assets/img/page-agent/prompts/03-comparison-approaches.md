# Comparison: Three Approaches to Web Automation

## Composition
A three-column comparison layout showing different web automation paradigms side by side.

## ZONES
- COLUMN 1 (LEFT) - "传统自动化" (Traditional): A robot arm clicking specific pixels on a screen, with XPath/CSS selector text floating around. Icons: Selenium, Puppeteer, Playwright logos sketched. A red X showing "breaks when DOM changes"
- COLUMN 2 (CENTER) - "视觉识别" (Vision-based): A camera/eye icon taking screenshots, sending to a heavy server with Python logo. Shows high latency with hourglass. Icons: browser-use. Yellow warning triangle for "expensive & slow"
- COLUMN 3 (RIGHT) - "Page Agent" (DOM脱水): A lightweight text document being read by an AI brain, directly inside a browser window. Green checkmark. Labels: "npm install", "no backend", "real-time". Highlighted border to show it's the recommended approach.

## LABELS
- Column headers: "选择器驱动", "截图+视觉模型", "DOM 文本 + LLM"
- Bottom comparison row: Speed meter showing relative speeds, Cost indicator, Integration ease
- Winner badge on Column 3: "前端友好 ✓"
