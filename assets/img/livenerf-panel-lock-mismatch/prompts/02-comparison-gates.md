# Illustration 02: 同一道校验门，画在左边那只齿轮里（有人推），右边那条流水线上根本没有这一格

16:9 横构图，手绘笔记风 + 浅色纸底。**画面里不允许出现任何可读文字、字母、数字、单词、
伪文字、乱码字形、logo、水印、签名**；抽象符号只用点、短横、斜线、勾、叉。

左半（占 46% 宽）：一台**简笔机器**——圆角矩形机身、顶上一个小漏斗、右侧一个齿轮。
齿轮内部画**三道窄槽**，其中**第三槽里卡着一枚锁形小图标**（锁梁闭合），
锁的上方有一根**短推杆**（灰蓝），表示"这一步只有机器真跑的时候才被推到"。
机身下方画**一条细出料口**，出口处只有**两三个断续的点**，暗示"这一路的产出留在机器内部，
外面看不见"。

右半（占 46% 宽）：一条**水平流水线**——底上一条直线轨道，轨道上均分站着**四个空心方框**
（表示流水线的四个工位），每个方框里各画一个抽象符号：①一个小漏斗、②一个叉形扳手、
③一张带三条横短线的小卡片、④一个空框里只有一小段斜线。
**四个方框里一律不许出现锁形图标**。轨道右端画一个**向下的箭头**（实线、粗描边），
箭头下面是一小片**平整的空格**（留白，什么都不放）。

中间分隔：左右之间画**一条竖直的淡虚线**（不是实线，不勾边到底，两端留空）。

线条与配色：纸底 #FDF6E3，勾边近黑 #2B2F36，主线条灰蓝 #6B7480，
**全图唯一的强调色是暗金 #E8C77A**，只给左边齿轮里那枚锁（填色），
右边流水线整体保持灰调。手绘抖动线条、略不闭合的拐角，40–50% 留白。
不要红色、不要渐变、不要 3D、不要写实金属、不要人物、不要表格线以外的网格。
