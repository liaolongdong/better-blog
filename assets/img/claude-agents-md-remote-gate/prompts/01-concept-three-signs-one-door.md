# 同一扇门上挂三块牌子，三块牌子互相不对

16:9 手绘笔记风概念图。主题：同一件事有三个口径，三个口径挂在同一个对象上，
彼此长度不一样——没有一个说法是空的，但它们说的不是同一件事。
画面不出现任何文字、字母、数字、勾叉符号。

构图：画面正中一扇门（与封面同一扇门，保持视觉连续：灰蓝 #9AA5B1 暗调门板 + 近黑 #1F2429 描边，
一个圆形门把手，门脚下是一小块手绘地板方块）。门板上半部**并排钉钉挂着三块横向长方形木牌**，
三块牌子上线齐平、间距相等，但**长度各不相同**：左牌最长、中牌中等、右牌最短，
每块牌面上只有两道很短的横杠（纯墨线笔画，不构成任何字），表示"各写了一句话"。

三块牌子的差异（本图全部意思都在这里）：
- **左牌**：暖黄 #E8C77A 底 + 近黑 #1F2429 描边，左上角和右上角各有一颗钉子，钉子画成小实心圆点。
- **中牌**：奶油纸底 #FDF6E3 + 灰蓝 #9AA5B1 描边，只有左上角一颗钉子，**右上角缺钉**，
  牌面向外翘起一个小角度（用一条弯曲的牌角表示），像挂不太住。
- **右牌**：深墨蓝 #2E3A47 底 + 近黑 #1F2429 描边、文字横杠改用亮色 #9AA5B1，
  这块牌**没有钉子**，是用一小段胶带斜贴在门板上的，胶带画成半透明浅灰梯形。

不一致的强调：三块牌子的下垂端各自指向门板上三个**不同高度**的位置；
从每块牌子底部引出一条极细的手绘虚线（虚线段很短、灰蓝 #9AA5B1），三条虚线在门把手上方
彼此**交叉一次**再各自落到门脚——交叉处不画任何符号，只用叠压表示对不上。

次要细节：门缝里透出暖黄 #E8C77A 的一条窄光；门脚地板方块右侧画一只很小的、
被踢到一边的小木凳（四条腿朝上），表示"挂这些牌子的人已经走了"。

配色：底 #FDF6E3 带细纸纹；门 #9AA5B1/#1F2429；三块牌 #E8C77A、#FDF6E3/#9AA5B1、#2E3A47；
虚线 #9AA5B1；门缝光与木凳高光 #E8C77A；一处极小面积的暗红 #FF6B6B 只用于中牌缺钉的那个空钉眼。
