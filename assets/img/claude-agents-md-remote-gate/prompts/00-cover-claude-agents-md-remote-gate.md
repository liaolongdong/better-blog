# Cover: 一扇立在自己地板上的门，电源线却插到远处云里的一台小机器上

16:9 横构图，手绘笔记风 + 深色底，画面里**不允许出现任何可读文字、字母、数字、伪文字、
横线占位符、勾选框里的符号**。整幅图只有三件事：一扇门、一条线、远处一台带开关的小机器。

主体（偏画面左三分之一）：一扇竖向的木门，微微开着一条缝，缝里透出暖黄 #E8C77A 的一小片光。
门板是灰蓝 #9AA5B1 的暗调填充 + 近黑 #1F2429 描边，门板上有两道竖向木纹斜线、一个圆形门把手。
门不嵌在任何墙里——它孤零零立在一块小的手绘地板方块上，方块下面有几条短斜线表示"这就是本地"。

线（关键，整张图的意思都在这条线上）：从门把手那一侧的门缝里，牵出一条**手绘电缆**，
线身近黑 #1F2429 描边 + 深墨蓝 #2E3A47 填充，线上有两道接缝。
这条线先向下出地板，再横穿画面中段，向右上方爬升，最后插进画面右三分之一处
一台悬浮的小机器（机箱：竖向长方形，圆角，机身正面有一个**拨动开关**，开关拨杆清楚地在**上方**，
开关旁边一小格亮色用暗红 #FF6B6B，表示"这一台说了算"）。

云：那台小机器装在一朵简笔云里——云用三到四个圆弧连成的封闭轮廓，灰蓝 #9AA5B1 描边，
内部不填充或填极淡的一档，云和机器之间留一小段空隙，让人一眼看出机器是被云托着的、不是本地的。
云的正下方**什么都不接**：不接地面、不接那扇门所在的地板。

人物（很小、不抢主体）：门的右侧、同一块地板方块上，站一个没有脸的火柴人形剪影，
侧身抬头看那条横穿画面的电缆，手里什么也没拿；剪影为近黑 #1F2429，不画五官、不画衣服细节。

光线：从门缝里透出的一束窄暖光打在门脚那一小块地板上；远处那台带开关的小机器上有一小圈
冷光晕。其余部分落在暗部。

配色：主背景深墨蓝 #1B2430，占三分之二以上；外围一条奶油纸底 #FDF6E3 的细纹边（不做完整边框）；
