# 两张并排的任务图：左边那条边在，右边那条边断了、一个节点孤在格子外

16:9 手绘笔记风流程图。主题：拼错一个键名之后，真正发生的事情不是"顺序晚了"，
而是"那个前置根本没进图"——图里少一个节点、少一条边，退出码却仍然全绿。
画面不出现任何文字、字母、数字、勾叉符号。

构图：画面左右各一块手绘的方格纸平台（每张 2×1 的两个大格子，格子线为浅灰蓝 #9AA5B1 细线、
略带抖动；两张平台**完全同尺寸同高度**），中间留一条空档。两块平台上各画两个节点方块，
节点是无圆角的正方形手绘块，边线近黑 #1F2429。

**左平台（边在）**：
- 左格子里一个节点：深墨蓝 #2E3A47 填充 + #1F2429 描边，节点右上角一小格亮色为薄荷绿 #88D8B0。
- 右格子里一个节点：同尺寸，暖黄 #E8C77A 填充 + #1F2429 描边，右上角亮格同为 #88D8B0。
- 两个节点之间有一条**实心带箭头的边**：从左边节点右缘出、箭头明确顶到右边节点左缘，
  线身 #1F2429 粗线、箭头处一小段 #88D8B0。边线略微上拱，像手绘。

**右平台（边断、节点出格）**：
- 右格子里的节点与左平台右格那个**同尺寸同色**（暖黄 #E8C77A），右上角亮格仍是薄荷绿 #88D8B0
  （强调：这一步照常跑完、照常"成功"）。
- 本应站在左格子里的那个节点，被画成**在平台外面的地面上**：位置在右平台左下角外侧、
  比平台低一格，尺寸比左平台那个节点略小一档，填充同样的深墨蓝 #2E3A47，
  但它右上角**没有**亮格，四周画三条极短的抖线表示"它落到了图外"。
- 从右平台那个暖黄节点的左缘，引出一条**断掉的花边线**：先向左走一小段，
  在半路以锯齿断面截断（断面露白），断口朝向地面那个出格节点；
  断口描边用暗红 #FF6B6B。断口与出格节点之间是一段明显的空距离，
  空档里画两个渐隐的小短杠，表示"这里本来该有一条边"。

次要细节：两块平台正下方各画一条很短的手绘横线当作"终端行"，
两条横线**长度一致、都是平的**（表示两次的退出码看起来一样），
