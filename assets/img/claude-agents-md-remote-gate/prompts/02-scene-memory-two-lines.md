# 一屏自查输出里，一行亮着、另一行是灰的，中间隔着一道线

16:9 手绘笔记风场景图。主题：官方给的自查动作本身带版本前提——
同一屏输出里，一类文件正常列出来，另一类要么缺席、要么被灰掉；
两者之间牵着一根细线，线的那头不在这一屏里。画面不出现任何文字、字母、数字、勾叉符号。

构图：画面主体是一块手绘的终端屏幕（横向圆角矩形，约占画面 60%，
机身 #2E3A47 填充 + 近黑 #1F2429 描边，屏幕内底是奶油纸色 #FDF6E3 压暗一档，
屏幕下方画一个小小的梯形底座）。屏幕里只有**三行横向内容条**，从上到下：
- **行一**：一条完整的、实心的暖黄 #E8C77A 横条，左端一颗小实心圆点，右端有一小段更亮的收尾
  （表示"这一行是正常列出来的"）。
- **行二**：与行一**同长同起点**的一条横条，但画成**空心描边 + 内部斜排细阴影线**，
  整体灰蓝 #9AA5B1，右端收尾处**断掉一小截**（缺的那一段用两三个渐隐的小短杠表示）。
- **行三**：比行一短一半的浅灰条，只作为背景里的第三行存在，不参与意思。

关键的线：从行二右端那个断口，牵出一条手绘细电缆（近黑 #1F2429 描边），
先向右上出屏幕边框，横穿画面右上区域，接到屏幕**外面**一朵简笔云里的
一台小机器（竖向圆角长方形，机身 #2E3A47，正面一个拨动开关，开关旁一小格亮色用暗红 #FF6B6B）。
云轮廓用三到四个圆弧，#9AA5B1 描边、内部不填色。这条线明确在屏幕之外，表示"决定行二的那件事不在这屏里"。

自查动作的小提示（不画文字的表达）：屏幕左上角外侧画一只简笔放大镜
（圆环 #9AA5B1 + 一小段手柄），放大镜的圆环正罩在行一的左端圆点上，
暗示"要自己一行一行看列表"。

人物（很小）：屏幕右下方的地面上站一个无脸火柴人剪影，仰头看那条飞出屏幕的电缆，
不画五官、不画衣服细节，剪影近黑 #1F2429。
