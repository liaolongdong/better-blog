# Illustration 2: 一行 model 字符串的真实走向

## Composition
A hand-drawn vertical flowchart on cream paper, 16:9, reading top to bottom
with one mid-flow branch to the right. A code chip at the top, a reroute gate
in the middle, two containers below it joined by a merge, and a dashed
consequence box hanging off the bottom. 45% of the canvas stays empty cream.

## ZONES
- TOP: one heading line, centred.
- NODE 1 (top, slightly left of centre): a rounded code chip drawn like a
  config value, holding the model string.
- EDGE: a short arrow down from NODE 1 into a gate.
- NODE 2 (centre): a reroute gate drawn as a small hinged flap on a pipe — the
  flap is drawn OPEN, tipped to the right, so the flow visibly leaves the
  straight path. A tiny date tag hangs off the hinge by a short string.
- BRANCH: from the gate, one arrow bends right into a container box; a second,
  much fainter arrow continues straight down and is drawn with a single coral
  slash across it, so the reader sees the straight path is the one NOT taken.
- NODE 3 (right of centre, below the gate): a container box holding the new
  model name.
- MERGE: arrows from NODE 2 and NODE 3 converge into a wide result bar at the
  bottom, drawn with a mint-green double underline.
- SIDE BOX: a dashed-outline box hanging below-left of the result bar,
  connected by a dashed line, holding two short stacked lines.

## LABELS
Exact strings, clean Chinese rendering, nothing else written anywhere:
- Heading: "9 月 14 日 12:00 之后"
- NODE 1 chip: "deepseek-v4-pro"
- Date tag on the gate hinge: "04:00 UTC"
- NODE 3 container: "V4.1 Flash"
- Result bar: "200 · 按 Flash 单价计费"
- Dashed box, first line: "CI 基线已换人"
- Dashed box, second line: "没有 5xx"

## COLORS
- Cream paper background #FDF6E3 with faint paper grain
- Dark ink #2B2B2B for all outlines, arrows and text
- Soft coral #FF6B6B for the slash across the untaken straight path
- Mint green #88D8B0 for the double underline beneath the result bar
- Warm yellow #FFD93D as a light marker sweep behind the NODE 3 container
- Muted grey #B8B2A7 for the dashed side box

## STYLE
- Hand-drawn sketch-notes: imperfect linework, visible wobble, small corner
  overshoots, no straightedge feel
- Marker-pen fills with visible stroke direction, never gradients
- Arrows drawn with a slightly uneven shaft and an open V arrowhead
- Generous negative space; nothing touching the outer 6% margin

## NEGATIVE
No logos, no UI screenshots, no browser chrome, no realistic humans, no faces,
no drop shadows, no 3D render, no photorealism, no watermarks. Do not invent
prices, token counts, latency numbers or percentages — only the LISTED strings
may appear as text.
