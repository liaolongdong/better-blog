安装后没反应？先看这三条

商店条目打不开

从仓库 Releases 下载 zip，在 chrome://extensions 打开右上角「开发者模式」，点「加载已解压的扩展程序」并选中解压目录。移动端 Chrome 不支持扩展，这一步要在桌面版完成。

安装了但工具栏没有图标

点地址栏右侧的拼图图标，找到这款扩展并点「固定」，然后刷新当前页面。Chrome 不会自动把新扩展放到工具栏。

更新后数据还在吗

这三款都把账号、规则或转换记录存在本机，正常更新扩展不会清掉；重要数据仍建议按仓库 README 的方式备份。
